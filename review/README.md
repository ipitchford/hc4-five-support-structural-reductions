# Internal editorial review

These five reports are role-separated, model-mediated assessments of the
single frozen target identified by `REVIEW_TARGET.sha256`. They were produced
inside the preparation workflow, without access to one another's report text.
They are not unaffiliated specialist review, independent reproduction, or peer
review.

Distribution-layer metadata added after review—DOI, repository URLs, release
hashes, manifests and Evidence Press deployment records—does not retroactively
become reviewed scientific content. Any scientific repair is recorded in
`RESPONSE_MATRIX.md` and subjected to one bounded confirmation pass.
