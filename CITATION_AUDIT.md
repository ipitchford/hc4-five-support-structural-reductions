# Citation audit

The manuscript uses primary mathematical sources for the Hessian-nilpotent
reduction, vanishing framework, binary-decimic invariant theory, coincident-root
loci, and conormal geometry. Bibliographic identifiers were checked against
publisher or arXiv records during preparation.

The pinned software/source dependency is identified separately in
`SOURCE_BRIDGE.md`; it is not presented as a peer-reviewed source. No reference
is used to imply that the present computation has been externally reviewed.

The bibliography is stored in `references.bib`, and the generated PDF is built
with Pandoc cite processing so unresolved citation keys fail visibly in the
text-extraction gate.
